# Jebe: Kaspi MCP для ChatGPT и Claude

Готовое MCP-подключение для продавцов Kaspi.kz. Вы добавляете один адрес в ChatGPT или Claude, и ваш ИИ видит магазин в [Jebe](https://jebe.kz), собирает накладные одним PDF, объясняет, почему не работает демпинг, и присылает предложения по ценам и остаткам. Применяете их вы.

Jebe независим и не связан с АО «Kaspi.kz». Название Kaspi используется, чтобы описать, с чем сервис работает.

Подробная страница с вопросами и ответами: **https://jebe.kz/kaspi-mcp**

> English: a hosted remote MCP server (Streamable HTTP) for Kaspi.kz marketplace sellers in Kazakhstan. It exposes the seller's store in Jebe (catalog, positions, orders, waybills to PDF, store memory) and lets the AI send change proposals that the store owner approves in the Jebe cabinet. This repository contains documentation and the registry manifest only; the service itself is not open source.

## Как подключить

1. Зарегистрируйтесь на [jebe.kz](https://jebe.kz) (7 дней бесплатно, без карты) и подключите магазин Kaspi.
2. В кабинете откройте «Ваш ИИ» и нажмите «Создать адрес подключения»: выберите магазины, права и срок (1, 3 или 7 дней).
3. Скопируйте адрес. Он как пароль: не публикуйте его.
4. Добавьте адрес в ChatGPT (раздел MCP или «Приложения») или в Claude («Коннекторы», «Добавить пользовательский коннектор»).
5. Напишите задачу или нажмите микрофон в приложении и скажите её голосом.

Адрес имеет вид `https://mcp.jebe.kz/s/<токен>/mcp`. Если ваш клиент умеет заголовки, можно использовать `https://mcp.jebe.kz/mcp` и заголовок `Authorization: Bearer <токен>`. Токен тот же. Транспорт: Streamable HTTP.

## Что умеет

- **Читать:** магазины и их настройки, города и точки, товары и позиции с фильтрами кабинета, карточку товара, причины, по которым бот не меняет цену, сводку магазина, активные заказы, архив продаж, память магазина и заметки к товарам.
- **Накладные:** обновить заказы из Kaspi и собрать нужные в один PDF (`waybills_refresh`, `waybills_pdf`).
- **Предлагать изменения:** минимальные, максимальные и разовые цены, остатки и предзаказ, настройки бота у позиций, выставление и снятие товара. Предложение приходит владельцу со сводкой «было → станет»; без его решения ничего не меняется. Автоприём включается владельцем по желанию, с суточным лимитом.
- **Помнить:** таблицы и правила работы магазина (до 100 МБ), чтобы ИИ не начинал с нуля в каждом чате.

Основные инструменты: `stores_list`, `products_list`, `positions_list`, `summary`, `active_orders`, `waybills_refresh`, `waybills_pdf`, `proposal_send`, `proposal_from_rule`, `proposal_from_file`, `proposal_cancel`, `memory_list`, `memory_put` и другие. Полный список ИИ получает при подключении.

## Что остаётся под вашим контролем

- ИИ не получает пароли, сессии Kaspi и платёжные реквизиты.
- Общие настройки магазина (активность, бот магазина, ночной подъём) ИИ только читает.
- Адрес действует 1–7 дней и отзывается кнопкой в кабинете: после отзыва обращения блокируются, неподтверждённые предложения отменяются.
